# Security Policy

Do not report suspected security vulnerabilities in public GitHub issues.

Public issues must never contain credentials, tokens, API keys, private URLs, customer data, payment information, KYC/KYB evidence, medical information, raw production payloads, internal logs, or other sensitive data.

If you believe you found a security vulnerability, submit it through [GitHub private vulnerability reporting](https://github.com/Agxium-Corporation/Agxium/security/advisories/new). Never use a public issue for vulnerability details.

Provide only the minimum information necessary to reproduce and assess the issue privately. Do not include real credentials, tokens, personal data, production payloads, or other sensitive data; redact them or use safe examples instead.

Public issues that expose sensitive information may be removed or redacted and moved to private handling.

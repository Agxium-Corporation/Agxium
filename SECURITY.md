# Security Policy

Do not report suspected security vulnerabilities in public GitHub issues.

Public issues must never contain credentials, tokens, API keys, private URLs, customer data, payment information, KYC/KYB evidence, medical information, raw production payloads, internal logs, or other sensitive data.

If you believe you found a security vulnerability, contact the Agxium maintainers through a private organization support/contact channel or GitHub private vulnerability reporting when available. Provide the minimum information necessary to reproduce the issue privately.

Public issues that expose sensitive information may be removed or redacted and moved to private handling.

# Agxium

Public hub for the Agxium ecosystem.

This repository is the single public place to:

- report bugs and unexpected behavior;
- request features and improvements;
- follow public milestones and roadmap progress;
- review the public backlog;
- provide product and developer feedback.

Agxium product source code is maintained in separate private repositories. This repository is for public planning and issue intake, not product source.

## Report a problem

Use **Issues → New issue → Bug report**. Search existing issues first and add information to an existing report when it describes the same problem.

Never include passwords, tokens, API keys, private URLs, customer data, payment data, KYC/KYB evidence, medical information, private logs, internal request/response bodies, or other sensitive information in a public issue.

## Request a feature

Use **Issues → New issue → Feature request**. Describe the problem or outcome first; implementation details are optional.

## Roadmap and backlog

Public milestones represent planned delivery targets. Open issues represent the public backlog. Milestone assignment means an item is planned for that target; it is not a contractual delivery commitment.

## Triage

Agxium team members and approved AI agents review new reports regularly. A report may be:

- accepted for engineering investigation;
- linked to an existing public report;
- marked as needing more information;
- closed as duplicate, not planned, or not reproducible.

When engineering work is required, Agxium tracks implementation in the appropriate private repository. The public issue remains the public reference without exposing private implementation details.

## Security

Do **not** report suspected security vulnerabilities as public issues. See [SECURITY.md](SECURITY.md).
